## 2. `purchase/components/purchaseOrderForm.tsx`

### Purpose
Complex form component for creating and updating Purchase Orders. Handles supplier selection, multiple line items with fraction unit support, tax computation, subtotal/nett computation.

### API Calls
Via `useSupplier` hook:
- `get({ search })` — Fetches suppliers for RemoteSelect dropdown

Via `useInventoryItem` hook:
- `get({ search })` — Fetches inventory items for line item RemoteSelect

Via `useItemFractions` (RTK: `useLazyGetItemFractionsQuery`):
- Endpoint: fetches fractions for a selected item — called when item is selected in a row
- Payload: `{ item_id: string }`

Form submit payload:
```ts
{
  supplier_id: string,
  ordered_at: string,        // date
  eta_date: string,          // date
  note: string,
  items: Array<{
    item_id: string,
    fraction_id: string,
    qty: number,
    price: number,
    discount: number
  }>
}
```

### Components Used
- `RemoteSelect` — Supplier selector (fetches via `useSupplier().get`), Item selector per row (fetches via `useInventoryItem().get`)
- `Select` — Fraction unit selector per row (populated after item selected)
- `Input` — qty, price, discount per row; note textarea
- `DatePicker` (single mode) — `ordered_at`, `eta_date`
- `Button` — Add row, Remove row, Submit

### State Management
- `useState` — `items: PurchaseOrderItem[]` (array of line items, each with `item_id`, `fraction_id`, `qty`, `price`, `discount`)
- `useState` — `fractionOptions: Record<string, FractionOption[]>` — per-item fractions keyed by row index
- `useItemFractions` — triggers fraction fetch on item select
- `useEffect` — Populates `fractionOptions` when fractions are fetched
- Derived computation: `subtotal`, `tax`, `nett` computed inline from `items`

### Table Config
None (uses manual row list).

### Filters
None.

### Forms
**Purchase Order Form** (`id="purchase-order-form"`):

| Field | Type | Required | Notes |
|---|---|---|---|
| supplier_id | RemoteSelect | Yes | Searches `/supplier` |
| ordered_at | DatePicker | Yes | Single date |
| eta_date | DatePicker | Yes | Single date |
| note | Textarea | No | Free text |
| items[].item_id | RemoteSelect | Yes | Searches `/inventory/item` |
| items[].fraction_id | Select | Yes | Loaded after item selected |
| items[].qty | Number Input | Yes | Min 1 |
| items[].price | Number Input | Yes | |
| items[].discount | Number Input | No | Default 0 |

Computed fields (display only): subtotal, tax (10%), nett.

### Modals
None.

### Props
```ts
interface PurchaseOrderFormProps {
  id: string                    // form element id
  isEdit?: boolean
  initialData?: any             // pre-populated data for update
  onSubmit: (data: PurchaseOrderFormData) => void
}
```
